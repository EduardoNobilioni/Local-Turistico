# Local Turístico — Conheça Busan

Página web desenvolvida como atividade do curso de Desenvolvimento Full Stack da **Rocketseat**, com o objetivo de praticar a estruturação de conteúdo com HTML e a estilização com CSS.

O projeto apresenta Busan, na Coreia do Sul, e destaca três de seus pontos turísticos: o Templo Haedong Yonggungsa, o Templo Beomeo-sa e o Parque Yongdusan. A página reúne imagens, descrições e indicações de passeios para diferentes interesses.

## Tecnologias

- **HTML5** para estruturar o conteúdo da página.
- **CSS3** para definir cores, tipografia, espaçamentos e apresentação das imagens.
- **Google Fonts** para carregar as fontes Open Sans e Alice.

## Aprendizados

- Organização do conteúdo com elementos como `header`, `main`, `section` e `footer`.
- Uso de imagens, textos alternativos e listas.
- Estilização com classes, IDs e variáveis CSS.
- Aplicação de margens, preenchimentos, bordas arredondadas e alinhamento de textos.

## Como executar

1. Acesse https://eduardonobilioni.github.io/Local-Turistico/
2. Navegue pela página para conferir o layout.

Não é necessário instalar dependências ou executar uma etapa de compilação. Para carregar as fontes do Google Fonts, é necessária uma conexão com a internet.

## Estrutura do projeto

```text
Local-Turistico/
├── assets/       # Imagens dos destinos e ícone de coração
├── index.html    # Conteúdo e estrutura da página
├── style.css     # Estilos da página

```
